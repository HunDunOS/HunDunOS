# 混沌 命名规范 v0.1

## 一、人读的名字：一律用完整拼音

**不用首字母缩写。** 缩写看起来短，但读的人要多跳一步「HD 是什么」，
而完整拼音读的人一眼就懂，还不用查表。

| 用 | 不用 | 说明 |
|---|---|---|
| `hundun.bao` | ~~`HD.bao`~~ | 根包（引导包）。全系统唯一必须靠名字找的东西，因为那时候还没有索引 |
| 混沌盘 | ~~HDGX 盘~~ | 盘格式。`HDGX` 只在魔数字段里出现 |
| 对象区 / 索引区 / 轴区 / 视图记录区 | | 盘上的分区 |
| 盘.xy 压缩.xy 盘格式.xy 内核对象.xy 界面.xy 应用.xy 主.xy | | 模块文件名一律中文 |
| 原语.asm | | 唯一允许存在的汇编模块 |

> 注：本文档之前那版叫 `HDGX`，是上一手起的缩写，作者已否决。**魔数字段保持 4 字节不动**
> —— 那是字节层的硬限制，跟人读的名字是两回事（见下）。

## 二、魔数：4 个字节，硬限制

盘上的魔数只能是 4 字节（读一个 u32 就知道是不是自己），所以这里**必须**用缩写。
但要把含义写在代码旁边，别让人猜。

| 魔数 | 十进制 | 出现位置 | 含义 |
|---|---|---|---|
| `HDGX` | `0x58474448` | 盘 LBA0/LBA1 偏移 0 | 混沌盘超级块 |
| `OBJ\0` | `0x004A424F` | 对象区每个扇区偏移 0 | 一个对象 |
| `XBOO` | — | 引导映像里的补丁表 | xboot 的补丁表 |
| `XYBP` | `0x50425958` | 内核入口 eax | XBP 引导协议握手 |

**写法要求**：一律用 `.ascii "HDGX"`，**不要**手写 `.long 0x58474448`。
让人手算小端序就是埋雷 —— 之前 XBP 那个魔数注释写的 `"XYBP"`，
实际值在内存里读出来是 `"PBYX"`，谁照着注释去找都会找不着。

## 三、扩展名

| 扩展名 | 内容 | 说明 |
|---|---|---|
| `.xy` | 新语源码 | 新语 = **x**in**y**u |
| `.bao` | 混沌包 | 包 = bāo。**容器格式**，不是对象类型 |
| `.iso` | 光盘映像 | 标准格式，不归我们管 |

**`.bao` 是容器格式，不是对象类型。** 对象的类型标签在内容里，而且**必须进哈希**
—— 靠后缀判断类型等于给「绕过内容寻址」开后门。

## 四、包名

```
hundun.bao        根包（引导包）。固定名字，超级块直接指它。
                  之所以必须固定：那会儿还没有索引，没法用哈希找。
zhishi-3f2a9c.bao 普通包：人读名字 + 内容哈希前 6 位。
                  人一眼能看出「都是知识包的不同版本」，机器只认哈希。
```

装完一个包之后，**包本身就不再必需了** —— 里面的对象已经进了对象区，装是幂等的。
