  新语怎么学 —— 一条路，四个台阶
════════════════════════════════════════════════════════════════════

  前提：仓库里有一份《文档/新语速查.md》（363 行），语法都在那儿。
        这份不重复它，只讲【按什么顺序读、每一步读什么、练什么】。

  总时长估计：半天能上手改，两天能独立改模块。

────────────────────────────────────────────────────────────────
  先记住一句话
────────────────────────────────────────────────────────────────

  新语不是"设计得漂亮的语言"，它是"照着这台机器长出来的语言"。
  所以学它别从语法表开始 —— **从一段真实的代码开始**，
  因为每一行都能对应到机器上真正发生的事。

  关键字只有 17 个，内建函数 40 来个。**一个下午够背完。**
  真正要花时间的是"这台机器怎么运转"，不是"这门语言怎么写"。

────────────────────────────────────────────────────────────────
  台阶一：读懂一段（20 分钟）
────────────────────────────────────────────────────────────────

  打开 模块/视图.xy，找这个函数：

      hs 视图_有能力(位: u32) -> u32 {
          kb 有: u32 = 视图能力[当前视图] wy 位
          rg 有 != 0 { fh 1 }
          fh 0
      }

  逐行对照：

      hs 视图_有能力(位: u32) -> u32
      └─ hs        = 函数（拼音"函数"）
         └─ 名字    = 可以是中文，随便写
            └─ (位: u32)  = 参数：名字:类型
                         └─ u32 = 32 位无符号（这台机器上一个"字"）
               └─ -> u32   = 返回 u32

      kb 有: u32 = ...   kb = 可变（拼音"可变"）绑定
                         有：`bl` 是不可变的。新语**默认不可变**，
                         想改必须写 kb —— 这一步是故意的

      视图能力[当前视图]  = 数组下标（跨模块的全局数组，.comm 合并成一份）
      wy                 = 位与（拼音"位与"）

      rg 有 != 0 { fh 1 }    rg = 如果（"如果"），fh = 返回（"返回"）

  读完这一个函数，你已经会了 6 个关键字里的 4 个。

▍台阶一的小练习（不改代码）
  打开 模块/盘格式.xy，找 索引找()，**用中文把每一行讲给自己听**。
  那个函数里有：数组、循环（dy/xh）、跳出（tc）、位运算、返回。
  如果你能讲顺，台阶一过了。

────────────────────────────────────────────────────────────────
  台阶二：写一个能跑的（1 小时）
────────────────────────────────────────────────────────────────

  别从零写新文件。**改一个已有的、最安全的地方**：

  ▍练习 A：加一条命令
    打开 模块/壳.xy，在 `执行()` 里找一个简单的命令，比如 `pan`
    （搜 `命令是("pan")`），照着它加一条：

        rg 命令是("niha") == 1 {
            屏设色(0x37C46A)
            屏串("  你好，我是新加的命令")
            换行()
            fh 0
        }

    然后：
        sh 构建/构建.sh "" /tmp/t.iso
        python3 工具/测试/跑桌面.py /tmp/t.iso 混沌盘.img /tmp/x "niha"

    看 /tmp/x/s.log 里有没有你打的那句话。
    ★ 这一步跑通，你的开发循环就通了 —— 后面全是重复它。

  ▍练习 B：算点东西
    把上面那条命令改成"算 1 到 10 的和"：

        rg 命令是("qiuhe") == 1 {
            kb i: u32 = 1
            kb 和: u32 = 0
            dy i <= 10 {
                和 = 和 + i
                i = i + 1
            }
            屏串("  1 到 10 的和 = ")
            屏数(和)
            换行()
            fh 0
        }

    这里你会碰到新语的三个坑（见下面第五节）：
      · 一个函数一个作用域，`kb i` 不能重复声明
      · 表达式不能跨行
      · 数组长度必须是常数

  ▍练习 C：碰一次内存（看一眼"危险要签字"）
        rg 命令是("shishi") == 1 {
            kb 缓[8]: u32 = 0          @ 局部数组
            kb 址: u32 = 0
            wx { 址 = 地址(缓) }
            wx { ^(址 + 0) = 65 }      @ 按【字节】写 —— 65 = 'A'
            wx { ^(址 + 1) = 0 }
            屏串(址)                  @ 应该打出一个 A
            换行()
            fh 0
        }
    ★ 注意：编译器会给你一行"危险统计"，告诉你这个文件里有几个 wx 块。
      这不是报错，是让你**数得清危险在哪**。

  ▍练习 D：让一条命令只在"有盘能力"的视图里能用
    在练习 A 那条命令开头加一行：

        rg 视图_要能力(8) == 0 { fh 0 }

    然后试：`cun hello` → `fen jia` → 在 jia 里敲你的命令 → 应该被拒。
    ★ 这一下你就摸到了这个系统的核心（能力即引用）。

  台阶三：读懂一个模块（半天）
────────────────────────────────────────────────────────────────

  按"好读程度"排：

  1) 模块/视图.xy（约 470 行）★ 建议从这个开始
     视图 / 分身 / 能力 —— 系统最核心的概念都在这儿
     读法：从 视图_初始化 开始，看一个视图是怎么建起来的
           然后 视图_签发 / 视图_切换 / 视图_载入 / 视图_存回
     注意：视图池是怎么存的（槽=字节的约定）

  2) 模块/盘格式.xy（约 390 行）
     盘长什么样：超级块 / 索引 / 对象区
     读法：盘格式化 → 盘存对象 → 盘取对象
     看点：写盘顺序（数据 → 索引 → 超级块，超级块是提交点）

  3) 模块/网卡.xy（约 900 行）★ 最难，但注释最全
     NE2000 寄存器操作 + ARP + IP + ICMP
     读法：卡写/卡读 → 网卡_找 → 复位 → 初始化 → 读PROM
           → 发帧 → 收帧 → ARP问/等 → 发PING/等PING
     看点：里面每一步都写了"为什么"（都是从 QEMU 源码里挖出来的坑）

  4) 模块/包.xy（约 400 行）
     .bao v2 怎么读、插件表（手）怎么挂

────────────────────────────────────────────────────────────────
  台阶四：改一个真 bug（从这个清单里挑）
────────────────────────────────────────────────────────────────

  从第三方那 294 条里挑"看得懂 + 改得动"的：

  ▍最简单：#213 盘总扇区硬编码 16384
     位置：模块/壳.xy 的 格式化 命令
     改法：用 ATA IDENTIFY 拿真实容量（要读 0x1F0 的 IDENTIFY 返回）
     难度：★★（要懂 ATA，但很短）

  ▍好上手：#264 前导零的数字字面量被当作八进制（010 == 8）
     位置：编译器/xyc.c 的词法分析
     改法：遇到 `0` 开头的数字别走八进制分支（或者只在 `0x` 时十六进制）
     难度：★★（C 代码，短）

  ▍有价值：#255 编译器 rlab[128] 溢出（14 个汉字的函数名就崩）
     位置：编译器/xyc.c 第 856 行附近，`sprintf(rlab, ".Lret_%s", mangle(name))`
     改法：改成 snprintf，或者按 strlen(mangled)+8 动态分配
     难度：★（改一行）
     ★ 这条值得先修 —— 中文标识符是这门语言的卖点

  ▍中等：#262 && 和 || 不短路
     位置：编译器/xyc.c 的二元运算生成（搜 "or eax, ecx"）
     改法：&& 要生成"左边为假就跳过去"，|| 同理。控制流生成，要小心
     难度：★★★

────────────────────────────────────────────────────────────────
  五、必踩的坑（背下来能省一整天）
────────────────────────────────────────────────────────────────

  1. 全局声明必须在【用之前】
     最稳的办法：所有 qj 都放文件开头。
     报错长这样：`名字不存在：工具LBA`

  2. 一个函数一个作用域
     同一函数里两个分支写 `kb x` 会冲突。
     报错：`第 N 行：x 已经绑定过了`

  3. 数组长度必须是常数
     `qj x[80 * 5]` 编不过 → 写 `qj x[400]`
     报错：`期望 ']'，实际是 '*'`

  4. 表达式不能跨行
     把一个调用拆成两行 → 报错。
     报错：`表达式里出现意外的 '行尾'`

  5. 参数是【不可变绑定】
     `hs f(长: u32)` 里不能 `长 = 60`
     要 `kb 实长: u32 = 长` 然后改 实长
     报错：`不可变绑定不可赋值：长（要可变请用 kb 声明）`

  6. 数组槽是 32 位（★ 最容易踩）
     `qj 缓[512]: u32` 里，`缓[i]` 落在字节 `4*i`。
     想按字节用，要么全程 `^(地址(缓) + k)`，要么全程"槽=字节"（别混）。

  7. 位与 `wy` 的优先级比 `==` 低（跟 C 一样）
     `a wy b == 0` 会解析成 `a wy (b == 0)` → **必须写括号**
     这条真实害过我：网卡 PCI 厂商号判断永远不成立。

  8. 保留但没实现的关键字：`jc` `mk` `wb` `nl`
     （"检查 / 模块 / 外部 / 内部" —— 给模块系统留的位置，别用）

────────────────────────────────────────────────────────────────
  六、三张表（贴墙上）
────────────────────────────────────────────────────────────────

▍关键字（一共 17 个）
    hs  函数       fh  返回       bl  不可变绑定   kb  可变绑定
    qj  全局       jg  结构体
    rg  如果       bz  不然
    dy  当要(条件循环)            xh  循环(无限)
    tc  跳出       jx  继续
    wx  危险块（写内存必须写在里面）
    jc  mk  wb  nl   ← 保留未实现，别用

▍类型
    u8 u16 u32 u64       无符号
    i8 i16 i32 i64       有符号
    z                    1 字节（等价 u8）★ 所以 z 不能当变量名
    *类型                指针
    （还有自定义结构体名）

▍内建函数（40 来个，挑常用的）
    屏幕/输入   屏宽 屏高 帧址 行宽 内存 毫秒 时 分 秒 睡(毫秒)
                键 鼠x 鼠y 鼠钮 轮询
    画          绘点(3) 取点(2) 绘块(5) 绘框(5) 绘字(4) 绘数(4) 绘十六(4) 绘块混(6)
                滚屏(2) 滚块(6)
    端口       端入 端入字 端出 端出字 端出32 端入32
    内存       读8 写8 读32 写32 地址(名字) 调用(地址,a,b,c,d)
    CPU       读CPUID CPUE CPUB CPUC CPUD
    其它       停机

    ★ 注意：壳.xy 里自己定义了 屏串 屏出 屏数 屏换行 屏清 印 印串 打十六 换行
      —— 那些是【新语写的函数】，不是内建。内建是直接进汇编的。

▍运算
    + - * /        （/ 是整除；除号不表示路径 —— 这是设计决定）
    == != < > <= >=
    wy 位与    yh 异或    （或：见速查）
    ^(p)  p[i]  .字段  取地址@
    ★ 注意：命名层用 `^` 表示"引用跳转"（替代 Unix 的 /），
      语言层 `^` 表示解引用 —— 同一个符号，都是"跨一次"的意思

────────────────────────────────────────────────────────────────
  七、练手沙盒（改哪最安全）
────────────────────────────────────────────────────────────────

  最安全  → 模块/壳.xy 的 执行()   加一条命令（只动一个函数）
  安全    → 模块/视图.xy            独立概念，逻辑干净
  中等    → 模块/盘格式.xy          动它会碰到盘上数据，测之前先备份 .img
  小心    → 模块/桌面.xy            40000+ 行，而且是拆分过的（拆分.py 会把函数
                                    分到四个模块，新加的函数必须补进分发表）
  别碰    → 运行时/图形.asm         手写汇编，出错就是三重故障，没有报错信息
  别碰    → 引导器/boot1.asm        512 字节，放不下东西，出错了机器都不亮

  ★ 改 模块/桌面.xy 有一条铁律：
    新加的函数必须同时加进 工具/拆分.py 的分发表，
    否则它会被分到【未分配】，静默丢掉，链接时才报 undefined reference。
    编译后看输出里有没有 [未分配]。

────────────────────────────────────────────────────────────────
  八、判断自己学会了没有
────────────────────────────────────────────────────────────────

  能通过这几条，就算上手了：

  □ 能在 壳.xy 里加一条命令，构建、跑通、在串口里看到自己的输出
  □ 看到 `名字不存在：xxx` 能立刻想到"全局声明在后面"
  □ 看到 `不可变绑定不可赋值` 能立刻改成 `kb`
  □ 知道 `qj 缓[512]: u32` 里 `缓[i]` 实际在字节 4i
  □ 知道 `a wy b == 0` 必须写括号
  □ 能讲清 视图_签发 / 视图_切换 做了什么
  □ 改完代码会**先跑一次**再说改好了

  ★ 最后一条最重要 —— 我自己今天在这上面栽过两次：
    说"修好了"但代码里根本没改；说"完全可以随时换"但一行都没实现。
    **"我说过" ≠ "改过了"。跑一遍再说话。**
