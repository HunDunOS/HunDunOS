  混沌 HunDunOS  ——  在电脑上（Linux）怎么用
════════════════════════════════════════════════════════════════════

  先说一句话，能省你半小时：
  ★ 这个项目的【工具链本来就是 Linux 程序】——
    xyc 是 clang 编出来的本机可执行程序，xiso/xbao 是 Python，
    构建全是 shell；跑起来也只需要 Linux 上的 QEMU。
    所以"编译成 Linux 版本"这件事【不需要做】，它已经是了。
    你缺的只是"电脑上要装什么 + 怎么跑"。

────────────────────────────────────────────────────────────────
  一、电脑上要装什么（一条命令）
────────────────────────────────────────────────────────────────

  先跑自检，它会告诉你缺什么、该敲什么命令：

      sh 装.sh

  Arch：    sudo pacman -S clang binutils python qemu-system-x86
  Debian：  sudo apt install clang binutils python3 qemu-system-x86
  Fedora：  sudo dnf install clang binutils python3 qemu-system-x86
  Alpine：  apk add clang binutils python3 qemu-system-i386

  ★ 如果你的电脑是 **x86_64**，到这里就够了 ——
    系统的 as/ld 自带 i386 支持（`as --32` / `ld -m elf_i386`），
    **不需要任何交叉工具链**。构建脚本会自动探测。

  ★ 如果不是 x86（比如 ARM 的笔记本、树莓派），还要装交叉工具链：
      Arch：    sudo pacman -S i686-linux-gnu-binutils
      Debian：  sudo apt install binutils-i686-linux-gnu
      Alpine：  apk add binutils-i586-alpine-linux-musl

────────────────────────────────────────────────────────────────
  二、三种用法（按你想干的事挑）
────────────────────────────────────────────────────────────────

▍用法 A：只想看看它长什么样（不构建）
  把两个文件放进一个目录：
      混沌桌面.iso        186368 字节
      混沌盘.img          8388608 字节
  然后：

      qemu-system-i386 -cdrom 混沌桌面.iso -boot d -m 256 -vga std \
        -drive file=混沌盘.img,format=raw,if=ide \
        -netdev user,id=n0 -device ne2k_pci,netdev=n0

  开机会进图形桌面 → 鼠标点【最右边那个坞图标】= 史书（终端）

  ★ 两个参数不能省：
      -drive ...混沌盘.img    ← 编辑器/C工具/插件三个包都在盘上
      -device ne2k_pci        ← 不加它 wang 会说"没找到"，网络全试不了

  ★ 想在电脑桌面上开个窗口看（不是无头跑）：
      把 -vga std 换成 -vga std -display gtk   （需要 qemu-ui-gtk）

▍用法 B：要改代码（这条是你以后天天走的）
      tar xzf 混沌-源码.tar.gz -C ~/混沌 && cd ~/混沌
      sh 装.sh                        ← 先确认环境
      sh 构建/构建.sh "" 混沌桌面.iso    ← 一条命令出 ISO（几十秒）

  改完代码 → 重跑上面那条构建 → 再跑 QEMU。

  ★★ 一条铁律：**改了内核，所有 .bao 都要重编**
      因为 .bao 里的代码是【位置相关】的，链接时借的是内核符号的绝对地址。
      内核一变地址就变，旧包里的调用全指向错地方。
          sh 构建/建包.sh      ← 编辑器包 → 写盘 LBA 8000
          sh 构建/建工具.sh     ← C 工具包 → 写盘 LBA 8100
          sh 构建/建插件.sh 插件/打印.xy dayin 8200

▍用法 C：想学新语（写 .xy → 编 → 跑）
  新语的源码是 .xy 文件。学习路径看《新语怎么学.txt》。

  最小的循环：在 模块/壳.xy 的 执行() 里加一条命令，然后构建 + 跑。
  例如加一条 niha：

      rg 命令是("niha") == 1 {
          屏设色(0x37C46A)
          屏串("  你好，我是新加的命令")
          换行()
          fh 0
      }

  构建 → 在史书里敲 niha → 应该看到你那句话。

  编辑器建议：**任何编辑器都行**（VS Code / vim / nano）。
  只有一条：文件编码必须是 **UTF-8**（标识符可以写中文，靠的就是这个）。

────────────────────────────────────────────────────────────────
  三、自动测（不用手点鼠标）
────────────────────────────────────────────────────────────────

      python3 工具/测试/跑桌面.py <iso> <盘img> <输出目录> "命令1,命令2,..."

  例：
      # 试对象存储
      python3 工具/测试/跑桌面.py 混沌桌面.iso 混沌盘.img /tmp/t "cun hello,lie,qu 0x4f9f2cab"

      # 试退格（! 前缀 = 只打字不回车）
      python3 工具/测试/跑桌面.py 混沌桌面.iso 混沌盘.img /tmp/t "!abc<bs>"

      # 试插件
      python3 工具/测试/跑桌面.py 混沌桌面.iso 混沌盘.img /tmp/t "zhuang 8200,dayin hello"

  输入的记号：
      <bs>      退格
      <left>    左方向键       <right>   右方向键
      前缀 !     只打字，不按回车

  它怎么工作：
      起 QEMU（无窗口）→ 用 QEMU 的 monitor 点鼠标/敲键盘 → 抓屏 → 读串口
      产物在输出目录：
          1桌面.ppm  2史书开了.ppm  5跑完.ppm   ← 屏幕（PPM 格式）
          s.log                                  ← 串口日志（★ 最重要）

  ★ 看屏幕：PPM 能直接看，也可以转 PNG：
      python3 -c "from PIL import Image; Image.open('5跑完.ppm').save('x.png')"

────────────────────────────────────────────────────────────────
  四、在电脑上开发，比在手机上舒服在哪
────────────────────────────────────────────────────────────────

  · 键盘能真打字（手机上是软件键盘，很多键发不出去）
  · 能开两个窗口：一个跑 QEMU，一个 `tail -f 输出目录/s.log` 看串口
    ★ 这是我最推荐的姿势 —— 边点边看日志，出问题一眼看到
  · 编辑器和终端并排，改一行 → 构建 → 跑 → 看日志，循环很快
  · `qemu-system-i386 ... -display gtk` 能直接在你桌面上开窗口点

  推荐的三个终端：
      # 1. 构建（改完代码在这里跑）
      sh 构建/构建.sh "" 混沌桌面.iso

      # 2. 跑 + 看串口（跑起来之后不要关）
      qemu-system-i386 -cdrom 混沌桌面.iso -boot d -m 256 -vga std \
        -drive file=混沌盘.img,format=raw,if=ide \
        -netdev user,id=n0 -device ne2k_pci,netdev=n0 \
        -serial file:/tmp/s.log -display gtk &
      tail -f /tmp/s.log

      # 3. 改代码

────────────────────────────────────────────────────────────────
  五、电脑上会遇到的问题（照着查）
────────────────────────────────────────────────────────────────

  ▍构建报 "unrecognised emulation mode: elf_i386"
    → 你的 ld 不支持 i386。装 binutils（x86_64 机器的 binutils 自带）
      或者在非 x86 机器上装交叉 binutils（看第一节）

  ▍构建报 "as: unrecognized option '--32'"
    → 同上。非 x86 机器的 as 不带 i386 后端

  ▍QEMU 报 "-drive: warning: short-form boolean option"
    → 那只是警告，不影响。用 `-drive file=xxx.img,format=raw,if=ide` 就没了

  ▍QEMU 直接退出，没报错
    → 内核三重故障了。这是 bug，把现象告诉我（截串口日志）

  ▍`wang` 说"没找到"
    → QEMU 启动参数里漏了 `-device ne2k_pci,netdev=n0 -netdev user,id=n0`

  ▍在 VMware 里网络用不了
    → 正常，VMware 没有 NE2000 这块卡（我接下来要加 e1000）

  ▍史书里 `zhuang` / `bianji` / `gongju` 报"读包失败"
    → 盘镜像没挂上，或者挂的不是那个 混沌盘.img
