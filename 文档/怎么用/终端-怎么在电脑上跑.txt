        混沌 HunDun 终端盘 —— 在电脑上的虚拟机里跑
════════════════════════════════════════════════════════════════

────────────────────────────────────────────────────────────────
零、先把文件名改回来
────────────────────────────────────────────────────────────────

  为了能发给你，文件后缀被改成了 .TXT（有些 App 会拦 .iso / .img）。用之前改回来：

      终端.iso.TXT     →   终端.iso
      混沌盘.img.TXT    →   混沌盘.img

────────────────────────────────────────────────────────────────
一、最省事：QEMU（一条命令）
────────────────────────────────────────────────────────────────

  Windows: 去官网下 QEMU for Windows，装完把 qemu-system-i386.exe 的目录加进 PATH
  macOS:   brew install qemu
  Linux:   apt install qemu-system-x86 / pacman -S qemu

  然后进到两个文件所在目录，敲：

      qemu-system-i386 -cdrom 终端.iso -boot d -m 256 -vga std -hda 混沌盘.img

  · `-vga std` 要给：终端是画在帧缓冲上的（见第三节）
  · 想省事不要盘？把 `-hda 混沌盘.img` 去掉就行 —— 能开机，只是不能存东西
  · 窗口太小可以加 `-full-screen`，或者用 `-display gtk`

────────────────────────────────────────────────────────────────
二、用 VirtualBox
────────────────────────────────────────────────────────────────

  1. 新建虚拟机
       类型：Other  /  Other/Unknown
       内存：256 MB 就够（给 512 也行）
       硬盘：**可以不建** —— 不建就只能看不能存

     想存东西就随便建个小盘（1 GB 足够，用默认的 VDI 就行，
     不需要我们那个 混沌盘.img —— 空白盘会被自动格式化）。

  2. 设置 → 系统 → 主板
       ☑ 启用 IO-APIC     （可有可无）
       ✗ 不要勾 EFI！  ← 这张盘是 BIOS 引导的，勾了 EFI 起不来

  3. 设置 → 存储
       光驱 → 选择磁盘文件 → 选 终端.iso

  4. 启动

────────────────────────────────────────────────────────────────
三、用 VMware / Hyper-V
────────────────────────────────────────────────────────────────

  VMware Workstation / Player
      · 新建虚拟机 → 稍后安装操作系统 → 其他
      · 固件类型选 **BIOS**（不要 UEFI）
      · 光驱挂 终端.iso → 启动

  Hyper-V
      · 新建 → 第 1 代  ← 必须是第 1 代（第 2 代只有 UEFI，起不来）
      · 内存 256 MB，不用连网
      · DVD 驱动器指向 终端.iso

  ★ 共同要点：**别用 UEFI**。这张盘是 El Torito / BIOS 引导的。

────────────────────────────────────────────────────────────────
四、为什么必须给图形（不能纯文本）
────────────────────────────────────────────────────────────────

  本来想做成纯文本模式的终端，但发现一个硬问题：

      VGA 文本模式每个字符格子只有 1 个字节，
      UTF-8 一个汉字 3 字节，塞不进去 —— 中文会全变成空白。

  所以终端改成**自己在帧缓冲上画字**：
      800x600x32 显存 → 自研点阵字库逐字画 → 自己管光标和滚屏

  代价是滚屏要用汇编（新语逐像素搬太慢），
  好处是**中文和 ASCII 一起显示**。

  如果你的虚拟机没有可用的 VBE 32 位色模式（很老的显卡模拟），
  引导器会退回文本模式，那时你只能看到 ASCII 部分。

────────────────────────────────────────────────────────────────
五、开机之后
────────────────────────────────────────────────────────────────

      混沌 HunDun  ·  内核能力终端
      --------------------------------
      [盘] 空白盘，正在格式化…
      [盘] 已有格式，世代 1，对象数 0

      输入 bang 看帮助。

      HD>

  键盘直接打字就行。可用命令：

      cun 内容     存对象 → 打印哈希
      qu 哈希      按哈希取回
      lie          列出盘上所有对象
      pan          盘状态
      shi          存几个中文示例（演示去重）
      bang         帮助
      qing         清屏
      guan         停机

────────────────────────────────────────────────────────────────
六、最值得试的三件事
────────────────────────────────────────────────────────────────

  ① 去重是白送的

        HD> cun hello
          已存 → 哈希 4f9f2cab   （1335831723）
        HD> cun hello
          已存 → 哈希 4f9f2cab   （1335831723）      ← 一模一样
        HD> pan
          … 对象数还是只 +1

     名字就是内容。同样的内容 → 同一个哈希 → 盘上不会存第二份。

  ② 关掉再开，东西还在

        HD> cun 今天天气不错
        （把虚拟机关掉电源，重新开机）
        HD> qu xxxxxxxx
          「今天天气不错」

     这不是"保存成文件"，是"对象已经在盘上了"。

  ③ 哈希不对就取不出来

        HD> qu 12345
          取不到：盘上没有这个哈希

     Unix 上你可以 open() 任意路径，路径字符串本身就是通行证。
     这里不行 —— 你手里得【先有】那个引用（哈希）。

────────────────────────────────────────────────────────────────
