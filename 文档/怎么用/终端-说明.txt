        混沌 HunDun —— 内核能力终端
        在虚拟机里体验「一切皆哈希」

────────────────────────────────────────────────────────────────
零、怎么跑
────────────────────────────────────────────────────────────────

  需要两个文件：
      终端.iso        光盘映像（引导用）
      混沌盘.img       8MB 空盘（用来存东西）

  一条命令：

      qemu-system-i386 -cdrom 终端.iso -boot d -m 256 -vga std \
                       -hda 混沌盘.img

  · `-vga std` 要给上 —— 终端是画在【帧缓冲】上的（见下面第三节）
  · Windows 上把 qemu-system-i386 换成完整路径
  · 没有盘也能开机，只是只能看不能存 —— 那就把 -hda 那段去掉

────────────────────────────────────────────────────────────────
一、开机之后你看到什么
────────────────────────────────────────────────────────────────

      混沌 HunDun  ·  内核能力终端          ← 中文能显示，因为是帧缓冲画的
      --------------------------------
      [盘] 空白盘，正在格式化…
      [盘] 已有格式，世代 1，对象数 0

      输入 bang 看帮助。

      HD>

  空白盘会自动格式化（写超级块、清索引区）。
  第二次开机就会显示「已有格式，世代 N，对象数 M」。

────────────────────────────────────────────────────────────────
二、能敲的命令
────────────────────────────────────────────────────────────────

  cun 内容        存一个对象 → 打印它的哈希
  qu 哈希         按哈希取回来（哈希不对就取不出来）
  lie             列出盘上所有对象（哈希 / 扇区号 / 内容）
  pan             看盘状态（版本 / 世代 / 对象数 / 追加指针）
  shi             存几个中文示例，演示去重
  bang            帮助
  qing            清屏
  guan            停机

────────────────────────────────────────────────────────────────
三、★ 为什么要用帧缓冲画，而不是普通文本模式
────────────────────────────────────────────────────────────────

  VGA 文本模式每个字符格子只有 **1 个字节**，塞不下中文（UTF-8 一个字 3 字节）。
  BIOS 时代的中文系统全靠"改字库 + 双字节编码"，那是另一套东西。

  所以这里的终端是**自己在帧缓冲上画字**：
      左侧 800x600x32 的显存 → 用自研点阵字库逐字画 → 自己维护光标和滚屏
  代价是滚屏要用汇编做（新语逐像素搬太慢），好处是**中文、ASCII 一起显示**。

  这也是"内核里最后一块汇编"存在的原因之一。

────────────────────────────────────────────────────────────────
四、最值得试的三件事
────────────────────────────────────────────────────────────────

  ① 去重是白送的

        HD> cun hello
          已存 → 哈希 4f9f2cab   （1335831723）
        HD> cun hello
          已存 → 哈希 4f9f2cab   （1335831723）      ← 一模一样
        HD> pan
          ... 对象数 还是只 +1

     名字就是内容。同样的内容 → 同一个哈希 → 盘上不会存第二份。

  ② 关掉再开，东西还在

        HD> cun 今天天气不错
          已存 → 哈希 xxxxxxxx
        （关掉虚拟机，重新开机）
        HD> qu xxxxxxxx
          「今天天气不错」

     这不是"保存到文件"，是"对象已经在盘上了、重启之后还在"。

  ③ 哈希不对就取不出来

        HD> qu 12345
          取不到：盘上没有这个哈希

     Unix 上你可以 open() 任意路径，路径字符串本身就是通行证。
     这里不行 —— 你手里得【先有】那个引用（哈希）。

────────────────────────────────────────────────────────────────
五、这台机器是什么
────────────────────────────────────────────────────────────────

  从引导扇区到此刻这个提示符，全部自己写：

      引导器        xboot（512 字节扇区 → VBE → 保护模式 → XBP 协议交棒）
      语言          新语（关键字全拼音，中文标识符，危险操作必须 wx{} 签字）
      编译器        xyc（C 写的 stage0）
      盘格式        混沌盘（超级块 / 对象区 / 索引区 / 轴区）
      压缩          LZSS（译自 0BSD 的 howerj/shrink）
      盘驱动        ATA PIO（用新语写的）
      帧缓冲控制台  自己画的（所以中文能上屏）
      最底层        原语.asm —— 全部汇编只剩端口读写和内存读写，816 字节

  内核是【可拆的】：13 个目标文件，不要哪个就从链接命令里删掉。

  借来并已标注的：字库位图来自 GNU Unifont。
