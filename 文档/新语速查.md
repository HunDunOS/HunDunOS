# 新语 (XinYu) 速查

编译器：`xyc`（stage0，C 写的，约 1100 行）
源码扩展名：`.xy`

> 设计原则：**关键字全部是拼音缩写，标识符支持中文，危险的动作必须显式签字。**

---

## 一、注释

```c
@ 这是注释（正式写法）
# 这也是（旧版 v0.3 的符号，兼容保留）
```

两者都是**注释到行尾**。其他符号（比如 `←`）不是注释，会编译报错。

---

## 二、关键字

| 关键字 | 拼音 | 含义 | 例子 |
|---|---|---|---|
| `hs` | 函数 | 定义函数 | `hs 主() -> u32 { }` |
| `fh` | 返回 | 返回值 | `fh 0` |
| `bl` | 绑定 | **不可变**绑定 | `bl x: u32 = 1` |
| `kb` | 可变 | **可变**绑定 | `kb i: u32 = 0` |
| `qj` | 全局 | 全局变量 | `qj 计数: u32` |
| `jg` | 结构 | 定义结构体 | `jg 点 { x: u32  y: u32 }` |
| `rg` | 如果 | 条件 | `rg x > 0 { }` |
| `bz` | 不然 | 否则 | `rg a { } bz { }` |
| `dy` | 当要 | 条件循环 | `dy i < 10 { }` |
| `xh` | 循环 | 无限循环 | `xh { }` |
| `tc` | 跳出 | break | `rg x == 0 { tc }` |
| `jx` | 继续 | continue | `jx` |
| `wx` | 危险 | 危险块 | `wx { ^p }` |

**保留但没实现的**：`jc` `mk` `wb` `nl`
（看名字大概是"检查 / 模块 / 外部 / 内部"，语言层面给模块系统留的位置）

## 三、类型

```
u8  u16  u32  u64     无符号
i8  i16  i32  i64     有符号
z                     1 字节（等价 u8）
*类型                 指针
```

**注意：`z` 是个类型，所以不能当变量名。**

## 四、核心设计：危险要签字

这是新语和别的语言最大的不同。

### 不可变是默认

```c
bl x: u32 = 1
x = 2
```
> 编译错误：`第 N 行：不可变绑定不可赋值：x（要可变请用 kb 声明）`

### 裸指针碰不得

```c
bl p: *u8 = "ABC"
kb c: u32 = ^p
```
> 编译错误：`第 N 行：解引用原始指针是危险操作，必须写在 wx { } 危险块内`

要碰就得开洞：

```c
wx { c = ^p }
```

### 编译器会数给你看

```
xyc: 新语 stage0 v0.4 -> 输出.s（2 字符串 / 0 全局 / 1 函数）
     危险统计：wx 危险块 1 个，原始指针操作 1 处
```

**这不是限制，是让危险显形。** 你一眼能数出一个文件里有几处可能出事的地方。

## 五、指针与地址

```c
bl 串: *u8 = "12345"
kb i: u32 = 0
kb 和: u32 = 0
xh {
    wx {
        rg ^(串 + i) == 0 { tc }      @ 按字节读
        和 = 和 + (^(串 + i) - 48)
    }
    i = i + 1
}
```

写一个字节：

```c
wx { ^(地址 + i) = 值 }
```

取变量的地址：

```c
kb 址: u32 = 0
wx { 址 = 地址(缓冲) }         @ 内建「地址(名字)」
```

### ★ 数组槽是 32 位

这是最容易踩的坑：

```c
qj 缓冲[512]: u32
缓冲[i] = 230          @ 实际写的是 4 字节：E6 00 00 00
```

所以当**字节数组**用的时候：

```c
wx { ^(缓冲址 + i) = 230 }     @ 这样才是 1 个字节
```

读也一样。

## 六、结构体

```c
jg 点 { x: u32  y: u32 }

qj 原点: 点              @ 全局结构体
qj 表[8]: 点             @ 结构体数组（可以）

原点.x = 3
表[2].y = 7
```

**限制：结构体不能作函数参数，也不能作返回值。** 要用就传下标：

```c
hs 取x(i: u32) -> u32 { fh 表[i].x }
```

## 七、函数

```c
hs 加(a: u32, b: u32) -> u32 {
    fh a + b
}
```

- **参数不可变**。要改先拷一份：

```c
hs 算(值: u32) -> u32 {
    kb v: u32 = 值        @ 拷一份才能改
    v = v * 2
    fh v
}
```

- **参数从左到右压栈**，所以进入被调函数时**第一个参数在更深的位置**。
  写汇编运行时时最容易搞错的地方：

```
第 1 个参数在 [esp + 4*n]
最后一个在 [esp + 4]
配合 pushad（32 字节）：
  参数 i（0 起，共 n 个）在 [esp + 36 + 4*(n-1-i)]
```

- **一个函数体是单一作用域**。多个分支里各写 `kb x` 会报"已经绑定过了"：

```c
hs 执行(a: u32) -> u32 {
    kb t: u32 = 0          @ 提到函数顶部
    rg a == 1 { t = 1  fh 0 }
    rg a == 2 { t = 2  fh 0 }
    fh 0
}
```

## 八、控制流

```c
rg 条件 { }
rg 条件 { } bz { }              @ bz 必须和 } 同一行！
dy 循环条件 { }
xh { }                          @ 无限循环
tc                              @ break
jx                              @ continue
```

`bz` 换行写会解析失败。

## 九、运算符

| 写法 | 含义 |
|---|---|
| `+ - * / %` | 算术（整数） |
| `== != < <= > >=` | 比较 |
| `wy` | 位与 |
| `wh` | 位或 |
| `yh` | 异或 |
| `<<` `>>` | 移位 |
| `!` | 逻辑非 |
| `^` | 解引用（必须在 `wx` 里） |
| `@`... | 见注释一节 |

**没有 `&&` 和 `||`**，要嵌套写：

```c
rg a > 0 {
    rg b > 0 { 都成立 }
}
```

## 十一、完整例子

```c
@ 算数组的和，并打印出来

qj 表[10]: u32
qj 和: u32

hs 主() -> u32 {
    kb i: u32 = 0
    dy i < 10 {
        表[i] = i * i
        i = i + 1
    }

    kb j: u32 = 0
    xh {
        rg j >= 10 { tc }
        和 = 和 + 表[j]
        j = j + 1
    }

    印("平方和 = ")
    印(和)
    印("\n")

    @ 用危险块读原始字节
    bl 串: *u8 = "新语"
    kb k: u32 = 0
    wx {
        xh {
            kb c: u8 = ^(串 + k)
            rg c == 0 { tc }
            印(c)
            印(" ")
            k = k + 1
        }
    }
    印("\n")
    fh 0
}
```

## 十二、错误信息对照

| 错误 | 原因 |
|---|---|
| `不可变绑定不可赋值：x` | 用 `bl` 声明的想改 → 改用 `kb` |
| `解引用原始指针是危险操作，必须写在 wx { } 内` | `^p` 没包在 `wx` 里 |
| `取地址是危险操作` | `地址(x)` 没包在 `wx` 里 |
| `x 已经绑定过了` | 同一函数里重复 `kb`（包括不同分支） |
| `声明必须跟一个名字` | 名字是关键字/类型（比如 `z` `dy`） |
| `参数类型缺失` | 结构体不能作参数类型 |
| `表达式里出现意外的 'bz'` | `bz` 换行了，要和 `}` 同一行 |
| `数组下标超出范围` | 运行时越界（会打印并停机） |
