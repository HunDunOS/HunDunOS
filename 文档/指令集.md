# 六爻 / 八卦 语言指令集（纯命令式编译版）

> 定稿依据：2026-11-12 主人给出的完整表
> 配套编译器：`lyc`（liuyao 仓库 `lyc.c`）

---

## 一、标点替换

| 码 | 字符 | 码 | 字符 |
|---|---|---|---|
| `00` | `#`（注释） | `05` | `;` |
| `01` | `(` | `06` | `@` |
| `02` | `)` | `07` | `^` |
| `03` | `"`（双引号） | `08` | `{` |
| `04` | `、`（顿号） | `09` | `}` |

**字符串铁律**：`03 … 03` 成对，是唯一的字符串定界符。`04` 是单个顿号分隔符，不成对。`03 … 04` 混搭是错误。

## 三、八卦分组规律

```
t_ = 乾（天，声明）    z_ = 泽（函数）
h_ = 火（运算）        l_ = 雷（控制）
f_ = 风（输入）        s_ = 水（输出）
r_ = 山（内存）        d_ = 地（数据）

每组 8 个，按 天泽火雷风水山地 顺序排入八卦位。
第二个字母同样按八卦序：乾 兑 离 震 巽 坎 艮 坤。
```

**例**：`ht` = 火天（加法）→ 第一个字 火、第二个字 天（乾）。
`lz` = 雷泽（相等则跳转）→ 雷 + 泽（兑）。
