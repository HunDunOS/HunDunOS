## 一、标点替换（十个数字码）

| 码 | 符号 | 说明 |
|---|---|---|
| `00` | `#` | 注释到行尾 |
| `01` | `(` | 左括号 |
| `02` | `)` | 右括号 |
| `03` | `"` | **字符串开头/结尾（双引号，可转义）** |
| `04` | `、` | **字符串开头/结尾（顿号，原样字节）** |
| `05` | `;` | 语句结束（等同换行） |
| `06` | `@` | 旧注释符（兼容保留） |
| `07` | `^` | 反斜杠 `\`，只在串里认 |
| `08` | `{` | 作用域开始 |
| `09` | `}` | 作用域结束 |

**规则**

- `03` 与 `03` 成对，`04` 与 `04` 成对，**不许交叉**。
  `03…04` 直接报错：`字符串没有闭合（" 开头要用 " 收尾）`。
- `03` 串里可以出现 `"`（要转义成 `\"` 才进内容）；`04` 串里可以**直接写 `"`**，不用转义 ——
  这就是它存在的理由：写汇编生成器时整句模板塞进去，不踩转义。
- `01/02/05/08/09` 前面必须是空白或标点，不能紧跟标识符。

**两种串在汇编里怎么出来**

```
03hello03           →  .asciz "hello"
04mov al, "A"04     →  .asciz "mov al, \"A\""     ← 源里没转义，编译器替你转
```

## 三、类型

五行单字：`J` 金（4，数值）　`M` 木（8，指针）　`S` 水（1，字节）　`H` 火（4，结构）　`T` 土（4，空）

五行配对：`JJ JM JS JH JT / MJ … / TT`，共 5×5 = 25 个，尺寸看第一个字。

老名字 `u8 u16 u32 u64 i8 i16 i32 i64 z` 保留为别名。

## 四、写代码的十条硬经验

```
01  标识符 ≥2 字符
02  不能撞 64 条指令
03  不能撞内建名
04  不能撞类型名
05  fh 后面不能套括号
06  括号层数要数清
07  主函数放最前（模块入口 = 链接基址第一个函数）
08  字符串 03…03 或 04…04，不许交叉
09  lr / ll 的配对要数清
10  全局变量用 ts，函数内用 tz，tz 不能进循环
```
